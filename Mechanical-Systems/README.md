# Mechanical Systems

Component and subsystem design for Destroyer-01.

## Baseline subsystems

| Subsystem | Baseline | Status |
|---|---|---|
| Bottom end | Forged 4340 crank and rods, forged 2618 pistons, 86 mm bore | provisional |
| Valvetrain | DOHC, 16 valves, bucket tappets, variable intake cam timing | provisional |
| Fuel system | Port injection, 4 bar, E100-compatible materials | provisional |
| Ignition | Coil-on-plug, cylinder-selective knock control | provisional |
| Lubrication | Wet sump, synthetic oil (grade TBD) | provisional |
| Cooling | Pressurised liquid cooling, 90 °C outlet target | provisional |
| Intake | Tuned manifold and 33 mm intake ports (port diameter provisional) | provisional |
| Exhaust | 4-2-1 header, material TBD | provisional |

## Status

Conceptual. The subsystem list and baseline choices are established; detailed design,
tolerances, and bills of materials are pending. See the
[Destroyer-01 specification](../Specifications/Destroyer-01-specification.md) and the
[constraint register](../Engineering-Constraints/constraints.md).
