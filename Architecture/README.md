# Architecture

Engine-level layout, system interfaces, and packaging.

## Current baseline

Destroyer-01(A): inline-4, DOHC 16-valve, naturally aspirated, port fuel injection, liquid-cooled,
E100 ethanol. See [`../Specifications/Destroyer-01-specification.md`](../Specifications/Destroyer-01-specification.md).

## Planned contents

- `engine-layout.md` — mounting, rotation, firing order, and major dimensions
- `interfaces.md` — coolant, oil, fuel, intake, exhaust, electrical, and ECU connections
- `packaging.md` — envelope, mass budget, and installation assumptions

## Status

Conceptual. The baseline architecture is defined; detailed interface and packaging documents
are pending. Changes that affect the baseline must be reflected in the specification and
constraint register.
